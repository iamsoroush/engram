# Active Session Workspace

## Purpose

Primary operational workspace for:
- capturing
- reviewing
- editing
- progressively processing sessions

This screen replaces the earlier separation between capture and review.

---

## Layout Structure

### 1. Session Header

Includes:
- patient identity or unknown state
- session title
- status badges
- quick actions

### 2. Clinical Report

Primary surface of the workspace.

The report should always exist, even while incomplete.

Possible states:
- generating
- partial draft
- processed report
- verified report

### 3. Collapsible Summary

AI-generated high-level clinical understanding.

Should remain:
- concise
- scannable
- clinically useful

### 4. Collapsible Extracted Findings

Structured extracted findings such as:
- procedure metadata
- measurements
- products
- injection sites

### 5. Expandable Source Captures

Includes:
- photos
- transcripts
- audio
- notes

These should feel like supporting evidence rather than uploaded files.

---

## Capture Philosophy

Captures append progressively to the current session.

The user should feel:
- safe capturing quickly
- confident about where captures are attached
- free to continue documentation naturally
