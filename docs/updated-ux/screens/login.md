# Login Screen

## Purpose

Authenticate the user with minimal friction.

The login experience should remain lightweight and fast.

---

## Elements

- Logo
- Clinic/workspace name
- Email or username input
- Password input
- Login button

Optional:
- Remember me
- Biometric login on mobile
- Session restore

---

## UX Principles

- Minimal visual noise
- Fast access
- Mobile-first layout
- Avoid enterprise/HIS feeling
