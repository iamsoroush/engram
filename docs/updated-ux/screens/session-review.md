# Session Review

## Purpose

Allow the user to review any session regardless of state.

Users should not be forced to verify or organize sessions before viewing them.

---

## Review Philosophy

Sessions remain reviewable:
- during capture
- during processing
- before verification
- after verification

The report is always the primary surface.

---

## Review Structure

1. Session header
2. Clinical report
3. Summary
4. Extracted findings
5. Source captures

---

## Quick Actions

- Verify session
- Assign patient
- Edit summary
- Continue capture
- Resume session
