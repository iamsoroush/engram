## Persistent Bottom Actions

Capture actions remain permanently visible:
- Record audio
- Take photo
- Write note

This preserves the feeling of:
- capture anywhere
- immediate documentation
- low-friction capture

When outside the active session workspace, users should choose where the new capture attaches:
- current session
- new session
- another session
