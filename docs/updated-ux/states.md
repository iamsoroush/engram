# States

## Session States

States are informative, not blocking.

Examples:
- Capturing
- Processing
- Needs review
- Unassigned
- Verified
- Failed

Users can review sessions in all states.

---

## Processing Philosophy

The report layout should remain stable while processing progresses.

Instead of replacing content with loading screens:
- partial reports appear progressively
- summaries improve progressively
- extracted findings improve progressively

---

## Verification

Verification is optional confirmation behavior.

Verification should:
- reduce uncertainty
- remove warning emphasis
- improve confidence

Verification should not:
- block access
- block editing
- block review
