# UX Overview

## Summary

AesMem is an AI-native clinical memory system for aesthetics clinics.

The UX is designed around:
- fast capture during visits
- patient-centered longitudinal memory
- progressive AI organization
- soft workflow instead of rigid workflow steps

The system should feel closer to a lightweight clinical memory workspace than a traditional HIS workflow application.

---

## Core UX Model

The product revolves around two primary objects:
- Patients
- Sessions

Workflow states are secondary metadata rather than primary navigation structures.

---

## Main Surfaces

### Active Session Workspace

Primary operational workspace for:
- capturing
- reviewing
- editing
- progressively processing sessions

### Patients

Primary long-term memory surface.

### Search

Global retrieval across:
- patients
- sessions
- captures
- extracted findings

---

## UX Philosophy

- Capture should never be blocked by organization requirements.
- Sessions remain accessible in all states.
- Verification reduces uncertainty instead of gating usability.
- AI progressively assists instead of enforcing workflows.
