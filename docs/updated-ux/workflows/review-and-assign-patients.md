# Workflow: Review and Assign Patients

## Goal

Allow flexible assignment and review without rigid workflow enforcement.

---

## Typical Flow

1. User opens Patients screen.
2. User reviews:
   - patient timelines
   - unresolved sessions
   - unassigned sessions
3. User may:
   - assign patient
   - verify session
   - continue capture
   - edit session
4. Session remains usable throughout.

---

## Important Behavior

Needs-review behavior should appear as:
- lightweight badges
- warnings
- confidence indicators

Avoid dedicated workflow queues for review.
