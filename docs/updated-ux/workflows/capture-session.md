# Workflow: Capture Session

## Goal

Allow clinicians to capture information with minimal interruption.

---

## Typical Flow

1. User opens Active Session Workspace.
2. User captures:
   - audio
   - photo
   - note
3. Captures append to current session.
4. AI progressively generates:
   - transcripts
   - summaries
   - extracted findings
   - report drafts
5. User may continue capturing or review immediately.

---

## Important Behavior

Capture should never require:
- prior patient selection
- verification
- organization completion
