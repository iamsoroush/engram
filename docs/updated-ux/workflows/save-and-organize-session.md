# Workflow: Session Evolution

## Goal

Support continuously evolving session objects instead of rigid workflow stages.

---

## Typical Flow

1. User captures information.
2. AI progressively processes the session.
3. User reviews session naturally during downtime.
4. User may assign or verify later.
5. Session becomes part of longitudinal patient memory.

---

## Important UX Principle

The user should never feel forced into:
- mandatory verification
- mandatory organization
- sequential workflow completion

Sessions remain usable in all states.
